# 🪟 Windows 11 Portfolio - Shreya Jolapara

Welcome to my interactive Windows 11 themed web portfolio! This application transforms a standard personal website into an authentic, responsive Windows 11 desktop experience right in your browser.

## 🚀 Overview

Built with Next.js 14, Tailwind CSS, Zustand, and Framer Motion, this portfolio highlights my projects, skills, experience, and achievements as an AI/ML student and full-stack developer.

## ✨ Key Features

- 💻 **Authentic Windows 11 Aesthetic**: Mica and Acrylic blur effects, Segoe UI typography, and custom dark mode styling.
- 🪟 **Window Management System**: Drag, resize, minimize, maximize, and stack windows with native Windows 11 frame controls.
- 📌 **Centered Taskbar & Start Menu**: Bottom centered taskbar with the 4-square Start button, Search flyout, system tray, and active indicators.
- ⚡ **Windows PowerShell Terminal**: Interactive command line supporting custom commands like `systeminfo`, `dir`, `tasklist`, `whoami`, and `skills`.
- 📁 **File Explorer**: Browse projects, resume, skills, and about sections using a file folder interface.
- 🤖 **Ask Shreya AI Assistant**: AI helper powered by Google Gemini to answer questions about my work and experience.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (React 18)
- **Styling**: Tailwind CSS & CSS Variables
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## 📦 Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shreya-J-5/windows_theme_portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd windows_theme_portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open `http://localhost:3000` (or `http://localhost:3001`) in your browser to explore!
